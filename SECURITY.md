# Security

Please report security bugs privately: open a private security advisory on the repository ([Report a vulnerability](https://github.com/vjk7989/h0x-ADE-core/security/advisories/new)). Don't open a public issue with exploit details.

Include your `h0x-core --version`, OS, whether the problem is local or remote, steps to reproduce, and the impact you expect. Remove secrets from logs and examples. A small reproduction helps.

Only the latest release is supported. We'll follow up in the private report; there's no fixed response deadline.

See [Security and trust](docs/security.md) for HyperOx core's access and trust model.
